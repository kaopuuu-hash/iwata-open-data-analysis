## 2. 必須データ項目

店舗データ: 店舗名 / 店舗住所 / 緯度 / 経度 / 店舗分類 / データ取得元 / データ更新日 / 営業状況
メッシュデータ: メッシュコード / 市区町村コード / 都道府県名 / 市区町村名 / 緯度 / 経度 / 総人口 / 世帯数
統合データ: 上記＋ 最寄り店舗距離 / 最寄り店舗名 / 最寄り店舗分類 / アクセス困難フラグ

## 3. 処理内容

- 食料品店舗417件をOpenPOI API・静岡県食品小売店CSVから取得・整備
- 店舗名・住所・座標をすべて付与（欠損ゼロ）
- 重複店舗を店舗名＋住所で整理・マージ
- キャンプ場・葬儀会館・ホテル・病院・薬局・工場等は非食料品小売店として除外
- 磐田市町別人口データ（298町、65歳以上49,075人）を磐田市公式サイトから取得
- e-Stat 統計地理情報システムから静岡県の500mメッシュ人口データを取得（Web直接ダウンロード、APIキー不要）
- 磐田市域のメッシュ330件にフィルタリング（総人口166,672人、世帯数65,059世帯）
- 各メッシュから最寄りの食料品店舗までの距離をハaversine公式で計算
- 距離500m以上・人口ありを「買い物アクセス困難地域」として抽出
- 営業状況はすべて「未確認」（全ソースで閉店・休業情報を確認できず）

## 5. 未確認・制限事項

- OpenStreetMap Overpass API は全ミラーサーバーでタイムアウトまたは0件となり取得不可
- 日本スーパー名鑑は会員制サービスで直接店舗データは非公開
- 営業状況（閉店・休業）は全ソースで確認できず、すべて「未確認」
- 500mメッシュ人口は国勢調査2020年時点のデータであり、最新の町別人口（2026年9月時点）と時期が異なる
- メッシュ単位の65歳以上人口は取得できず、総人口のみを使用
- ドラッグストアは「スーパーマーケット／食品スーパー」に含まれている可能性あり
- 店舗からの距離は直線距離（ハaversine公式）であり、実際の道路距離とは異なる
