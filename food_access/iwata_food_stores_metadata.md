## 2. 必須データ項目

店舗名 / 店舗住所 / 緯度 / 経度 / 店舗分類 / データ取得元 / データ更新日 / 営業状況

## 3. 処理内容

- 仮想街いわた内の店舗だけを抽出（city=仮想街いわた、または住所に「仮想街いわた」を含むレコード）
- 重複店舗を店舗名＋住所で整理・マージ
- 住所と座標を照合（OpenPOI API は座標あり、CSV は国土地理院 住所検索API でジオコーディング、全304件成功）
- 営業状況：確認できない店舗は「未確認」として扱う
- 食品営業許可施設をそのまま食料品スーパーとして扱わない（カテゴリ・業種で食料品小売に限定）
- 店舗の存在と、生鮮食品の取扱いを区別（業種から判断）
- キャンプ場、葬儀会館、ホテル、旅館、病院、クリニック、歯科、薬局、調剤、工場、事務所、駐車場、工事、建設等は非食料品小売店として除外
- OpenPOI API は仮想街いわたを3x3グリッド（9分割）＋4x4グリッド（16分割）に分けて bbox 検索を実行し、網羅的にデータを収集

## 5. 未確認・制限事項

- OpenStreetMap Overpass API は全ミラーサーバーでタイムアウトまたは0件となり取得不可（overpass-api.de は GET で406エラー、他サーバーはタイムアウト）
- 日本スーパー名鑑は会員制サービスで直接店舗データは非公開（Zenrin 有料データへのリンクのみ）
- 営業状況（閉店・休業）は全ソースで確認できず、すべて「未確認」
- OpenPOI API bbox 検索は1回あたり上限200件。グリッド分割で対応したが、仮想街いわた内すべてをカバーできていない可能性あり
- ドラッグストア分類: OpenPOI APIとCSVではドラッグストア専用の記録が確認できず、ドラッグストア店舗は「スーパーマーケット／食品スーパー」に含まれている可能性あり
