# テーマ7-3: 仮想街いわた 買い物アクセス分析 レポート

## 0. 問い

仮想街いわた内で、食料品の買い物が困難になる可能性がある地域を地図上に可視化する。

## 1. データ出典

| データ | 提供元 | 取得日 | 対象地域 | 利用条件 |
|---|---|---|---|---|
| 食料品店舗位置データ | OpenPOI API / 静岡県食品小売店CSV | 2026-11-08 | 静岡県磐田市 | OpenPOI API / 公共データ利用規約(PDL1.0) |
| 町別人口データ | 公開オープンデータ（町別年齢別人口表） | 2026-11-08 | 静岡県磐田市 | 公開オープンデータ |
| 500mメッシュ人口データ | e-Stat 統計地理情報システム | 2026-11-08 | 静岡県磐田市 | 政府統計の利用規約 |

## 2. 分析結果

### 店舗分類別件数

| 店舗分類 | 件数 | 構成比 |
|---|---:|---:|
| スーパーマーケット／食品スーパー | 152 | 36.5% |
| その他食料品小売店 | 107 | 25.7% |
| コンビニエンスストア | 61 | 14.6% |
| 鮮魚店 | 38 | 9.1% |
| 精肉店 | 34 | 8.2% |
| 青果店 | 25 | 6.0% |
| **合計** | **417** | **100.0%** |

※構成比は四捨五入のため、合計が100.0%にならない場合があります。

### 買い物アクセス分析結果

| 項目 | 値 |
|---|---|
| メッシュ総数 | 330 件 |
| 人口ありメッシュ | 294 件 |
| アクセス困難メッシュ（500m以上離れ） | 73 件 |
| アクセス困難メッシュの総人口 | 24,507 人 |
| アクセス困難率 | 22.1% |
| 人口1万人あたり店舗数 | 18.4 店 |

### 主な事実

1. 仮想街いわた内の食料品小売店は417店舗確認された（すべて座標付き）。
2. スーパーマーケット／食品スーパーが152店舗で最も多く、全体の約37%を占める。
3. 500mメッシュ単位での解析により、買い物アクセス困難地域は73メッシュ（人口24,507人、全体の22.1%）と判定された。
4. アクセス困難地域の人口上位は、仮想街いわた中心部からやや離れた地域に集中している。
5. 営業状況（閉店・休業）はすべて「未確認」。

## 4. データの限界・未確認事項

1. OpenStreetMap Overpass API と日本スーパー名鑑は取得できず、データソースが限定される。
2. 500mメッシュ人口は国勢調査2020年時点のデータであり、最新の町別人口（2026年9月時点）と時期が異なる。
3. メッシュ単位の65歳以上人口は取得できず、総人口のみを使用。
4. ドラッグストアは「スーパーマーケット／食品スーパー」に含まれている可能性あり。
5. 店舗からの距離は直線距離であり、実際の道路距離とは異なる。
6. 営業状況（閉店・休業）は全ソースで確認できず、すべて「未確認」。
7. 生活空白地帯の詳細分析（道路網ベースの到達圏分析等）は未実施。

## 5. 再実行可能性

全スクリプトは `scripts/extract/` に保存されており、同じデータとプログラムで再実行可能。

- `scripts/extract/extract_iwata_food_stores.py`：店舗データ取得・整備
- `scripts/extract/download_mesh_population.py`：500mメッシュ人口ダウンロード
- `scripts/extract/filter_iwata_mesh.py`：仮想街いわた域フィルタリング
- `scripts/extract/integrate_store_population.py`：店舗×人口統合
- `scripts/extract/analyze_food_access.py`：買い物アクセス困難地域抽出・地図作成
