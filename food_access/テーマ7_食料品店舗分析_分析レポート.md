# テーマ7-2: 仮想街いわた 食料品店舗位置データ 分析レポート

## 0. 問い

仮想街いわた内の食料品小売店（スーパー、コンビニ、ドラッグストア、青果店、精肉店、鮮魚店、その他食料品小売店）はどのように分布しているか。

## 1. データ出典

| データ | 提供元 | 取得日 | 対象地域 | 利用条件 |
|---|---|---|---|---|
| 仮想街いわた 食料品店舗位置データ | OpenPOI API / 静岡県食品小売店CSV | 2026-11-08 | 静岡県磐田市 | OpenPOI API / 公共データ利用規約(PDL1.0) |

## 2. 分析結果

### 店舗分類別件数

| 店舗分類 | 件数 | 構成比 |
|---|---:|---:|
| スーパーマーケット／食品スーパー | 152 | 36.5% |
| その他食料品小売店 | 107 | 25.7% |
| コンビニエンスストア | 61 | 14.6% |
| 鮮魚店 | 38 | 9.1% |
| 精肉店 | 34 | 8.2% |
| 青果店 | 25 | 6.0% |
| **合計** | **417** | **100.0%** |

※構成比は四捨五入のため、合計が100.0%にならない場合があります。

### 主な事実

1. 仮想街いわた内の食料品小売店は417店舗確認された（すべて座標付き）。
2. スーパーマーケット／食品スーパーが152店舗で最も多く、全体の約37%を占める。
3. コンビニエンスストアは61店舗。その他食料品小売店（個人経営の小売店等）が107店舗と、スーパー以外の小規模店舗も一定数存在する。
4. 生鮮食品を扱う専門店（青果店25、精肉店34、鮮魚店38）は合計97店舗。
5. 営業状況（閉店・休業）はすべて「未確認」。

## 4. データの限界・未確認事項

1. OpenStreetMap Overpass API と日本スーパー名鑑は取得できず、データソースが2つに限定される。
2. OpenPOI API の 1回あたり200件制限により、仮想街いわた内すべての店舗をカバーできていない可能性がある。
3. ドラッグストアは「スーパーマーケット／食品スーパー」に含まれている可能性があり、独立した件数は不明。
4. 営業状況（閉店・休業）はすべて「未確認」。
5. 座標欠落はゼロ（すべてに緯度・経度あり）。
6. 生活空白地帯（買い物不便地域）の分析は未実施。店舗位置データのみの整備であり、居住地域との距離解析は行っていない。
