# 公開オープンデータ GIS可視化 提案書

## 1. 概要

Phase 1-3で収集・分析した15テーマのデータを、GIS（地理情報システム）のように統合的に可視化するWebマップを構築する提案です。

## 2. 目的

- 複数のデータレイヤーを重ね合わせて空間的な関係性を把握
- 一般市民や行政担当者が直感的にデータを理解できる
- 分析結果の検証と新たな発見の促進

## 3. 利用可能なデータ（座標付き）

| データ | 件数 | 座標 | テーマ |
|---|---:|---|---|
| 公共施設 | 135 | ✅ | T1 |
| バス停 | 714 | ✅ | T8 |
| 公園 | 93 | ✅ | T10 |
| 観光施設 | 37 | ✅ | T5 |

## 4. 提案する可視化レイヤー

### Layer 1: 基盤レイヤー
- 行政区域境界
- 都市計画区域
- 市街化区域
- 河川・道路

### Layer 2: 施設レイヤー（ポイント）
- 公共施設（種別別色分け）
- バス停（コミュニティバス/一般）
- 公園（面積別サイズ）
- 観光施設
- 避難所
- 医療機関（ジオコーディング後）
- 介護サービス事業所

### Layer 3: リスクレイヤー（ポリゴン/ヒートマップ）
- 洪水浸水想定区域（浸水深別）
- 土砂災害警戒区域
- 生活空白地帯（バス停密度）
- 暑熱リスク

### Layer 4: 統計レイヤー（コロプレス）
- 町別人口
- 高齢化率
- 製造業従業者密度
- 公園面積/人口比

### Layer 5: 分析結果レイヤー
- 施設分布クラスター
- 到達圏（バス停からの徒歩500m圏）
- 空白地帯の可視化

## 5. 技術提案

### 5.1 推奨技術スタック

| コンポーネント | 技術 | 理由 |
|---|---|---|
| 地図ライブラリ | Leaflet.js | 軽量、オープンソース、日本語対応 |
| ベースマップ | OpenStreetMap / 国土地理院タイル | 無料、高品質 |
| データ形式 | GeoJSON | Web標準、Leaflet対応 |
| ヒートマップ | Leaflet.heat | 密度可視化 |
| クラスタリング | Leaflet.markercluster | 大量ポイント表示 |
| コロプレス | Leaflet choropleth | 統計データ表示 |

### 5.2 アーキテクチャ

```
┌─────────────────────────────────────┐

│  └── population_choropleth.geojson  │
├─────────────────────────────────────┤

```

### 5.3 実装手順

#### Step 1: GeoJSON変換スクリプトの作成
- CSV/Shapefile → GeoJSON変換
- 座標系の統一（WGS84）
- 属性データの付与

#### Step 2: Webマップの構築
- Leaflet.jsベースのHTMLファイル
- レイヤーコントロール
- ポップアップ情報
- 凡例

#### Step 3: データ統合
- 全レイヤーの統合表示
- フィルタリング機能
- 検索機能

#### Step 4: デプロイ
- GitHub Pages またはローカルHTML
- レスポンシブデザイン

## 6. 実装の優先順位

### Phase A: 基本マップ（1-2日）
1. ベースマップ + 施設ポイントレイヤー
2. レイヤートグル機能
3. ポップアップ情報

### Phase B: リスクレイヤー（1-2日）
4. 洪水・土砂災害ゾーン
5. 生活空白地帯ヒートマップ
6. バス停密度ヒートマップ

### Phase C: 統計レイヤー（1日）
7. 町別人口コロプレス
8. 高齢化率コロプレス

### Phase D: 高度な分析（2-3日）
9. 到達圏分析（isochrone）
10. クラスタリング分析
11. ダッシュボード統合

## 7. 期待される効果

1. **直感的な理解**: 地図上でデータの空間分布を即座に把握
2. **関係性の発見**: 複数レイヤーの重ね合わせによる新たな発見
3. **市民参加**: 一般市民がデータを容易に理解・活用
4. **行政支援**: 政策立案の基礎資料として活用
