# テーマ10: 公園・緑地分析 レポート（v2・作り直し）

## 0. 問い・仮説（工程1）

- **問い**：仮想街いわたの公園はどこにどれだけあり、設備はどうか。
- **仮説**：公園は地区ごとに配置され、遊具・トイレを備えるものが多い。
- **検証方法**：都市公園一覧93件の種別・地区・面積・設備有無を集計する。人口分布との対応、緑地面積全体の評価は行わない（人口の空間分布・公園以外の緑地データがないため）。

## 3. 結論（事実のみ）

1. 公園93カ所、総面積118.79haが公開されている。
2. 磐田地区に49件（52.7%）が集中する。人口分布との対応は検証できない。
3. 遊具あり63件、トイレあり69件である。これらが多いかどうかの判定は行わない。
4. 公園以外の緑地（農地・山林等）は含まない。

## 4. データの限界・未確認事項

1. データは2017年時点（約9年古い）。
2. 公園の利用者数は未取得。
3. 緑地面積（公園以外）は未取得。
4. 公園の老朽化状況は未取得。
5. 全国平均・他市との比較は未実施。
