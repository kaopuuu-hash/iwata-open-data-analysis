## 3. 更新提案

### 3.1 優先度: 高

#### 3.1.1 バス停データ（2010年 → 2022年）
- **現状**: 平成22年度データ（14年前）
- **更新先**: 国土数値情報 v3.0（令和4年度）
- **URL**: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P11-v3_0.html
- **影響**: Theme 8, 9の分析結果が大幅に変わる可能性
- **工数**: 1日

#### 3.1.2 人口データ（2021年 → 2024年）
- **現状**: 2021年3月31日時点
- **更新先**: LinkData (rdf1s2623i, rdf1s2622i)
- **影響**: Theme 2, 4, 9, 14の分析結果
- **工数**: 0.5日

#### 3.1.3 災害リスクデータ（2017-2018年 → 2024年）
- **現状**: 洪水2018年、土砂2017年
- **更新先**: 国土数値情報 最新版
- **影響**: Theme 11, 12の分析結果
- **工数**: 1日

### 3.2 優先度: 中

#### 3.2.1 公共施設データ（2016年 → 2024年）
- **現状**: 2016年2月公開
- **更新先**: LinkData (rdf1s4257i)
- **影響**: Theme 1, 4, 6の分析結果
- **工数**: 0.5日

#### 3.2.2 公園データ（2017年 → 2024年）
- **現状**: 2017年6月公開
- **更新先**: LinkData (rdf1s3748i)
- **影響**: Theme 10の分析結果
- **工数**: 0.5日

#### 3.2.3 避難所データ（2017年 → 2024年）
- **現状**: 2017年10月公開
- **更新先**: LinkData (rdf1s3385i)
- **影響**: Theme 12の分析結果
- **工数**: 0.5日

## 4. 更新実施計画

### Phase 1: 高優先度データの更新（2-3日）
1. バス停データ (v3.0) のダウンロード・変換
2. 人口データ (2024年) のダウンロード
3. 災害リスクデータ (2024年) のダウンロード

### Phase 2: 中優先度データの更新（1-2日）
4. 公共施設データの再ダウンロード
5. 公園データの再ダウンロード
6. 避難所データの再ダウンロード

### Phase 3: 分析の再実行（1-2日）
7. 影響を受けるテーマの分析スクリプト再実行
8. レポートの更新
9. GISマップの更新

## 5. 更新による期待される変化

| テーマ | 変化の程度 | 理由 |
|---|---|---|
| Theme 8 (公共交通) | 大 | バス停データが14年古い |
| Theme 9 (生活空白) | 大 | バス停データに依存 |
| Theme 11 (災害リスク) | 中 | 浸水想定区域の更新 |
| Theme 12 (避難・孤立) | 中 | 避難所の追加・変更 |
| Theme 1 (公共施設) | 小 | 施設の追加・変更 |
| Theme 10 (公園) | 小 | 公園の追加・変更 |
| Theme 2 (人口構造) | 小 | 人口微減 |

## 6. 推奨する次のアクション

1. **Phase 1から開始**: バス停・人口・災害リスクデータの更新
2. **影響分析**: 更新後のデータで分析結果の変化を確認
3. **レポート更新**: 変化が大きい場合はレポートを更新
