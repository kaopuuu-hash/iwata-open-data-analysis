# テーマ4: 子育て環境分析 レポート（v2・作り直し）

## 0. 問い・仮説（工程1）

- **問い**：児童人口に対して子育て関連施設はどう配置されているか。対象年齢別の偏りはあるか。
- **仮説**：小学校・保育施設は児童人口に対応して配置され、年齢層間の偏りは小さい。
- **検証方法**：施設種別ごとの件数と、対象年齢人口（2021年）に対する千人当たり件数を算出する。充足度の判定は行わない（定員・利用者数データがないため）。

## 3. 結論（事実のみ）

1. 件数が最も多いのは放課後児童クラブ（41件）であり、対象人口当たりでは4.4/千人（6-11歳）となる。
2. 学校（小22・中10）は対象人口当たり2.4/千人・2.1/千人、保育園＋こども園は3.2/千人（0-2歳）である。
3. これらの数値が足りているかどうかは判定できない。定員・利用者数・待機児童数のデータが存在しないためである。
4. 施設の空間的分布（均等配置かどうか）は検証できない。学区・到達圏のデータが存在しないためである。仮説の後半は検証不能。

## 4. データの限界・未確認事項

1. 施設（2016年）と人口（2021年）の時点が異なる。
2. 定員・利用者数・待機児童数は未取得。
3. 学区データ・到達圏データは未取得のため、分布の分析は不可。
4. 子育て支援センター9カ所の利用圏は未検証。
