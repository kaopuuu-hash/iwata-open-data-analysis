# GIS拡張 可能性の優先度提案

再現性（実装の容易さ・データの入手性）が高い順に提案します。

## 優先度ランキング

### Tier 1: 即座に実装可能（再現性: 高）

#### 1. 生活空白地帯ヒートマップ
- **再現性**: ★★★★★
- **データ**: Theme 9で計算済み（void_cells.csv）
- **作業**: CSV → GeoJSON変換 + Leaflet.heatプラグイン
- **工数**: 0.5日
- **内容**: バス停密度のヒートマップ表示、空白地帯の強調

#### 2. バス停密度ヒートマップ
- **再現性**: ★★★★★
- **データ**: Theme 8のバス停座標データ
- **作業**: Leaflet.heatで密度表示
- **工数**: 0.5日
- **内容**: バス停の密度をヒートマップで表示

#### 3. 公園面積コロプレス
- **再現性**: ★★★★☆
- **データ**: Theme 10の公園データ（地区別集計済み）
- **作業**: 地区別公園面積/人口比の色分け
- **工数**: 1日
- **内容**: 地区別の公園面積/人口比を色分け表示

### Tier 2: 中程度の工数（再現性: 中）

#### 4. 洪水浸水想定区域ポリゴン
- **再現性**: ★★★☆☆
- **データ**: 国土数値情報 Shapefile（取得済み）
- **作業**: Shapefile → GeoJSON変換 + Leafletポリゴン表示
- **工数**: 1-2日
- **内容**: 浸水深別（0.5m/0.5-3m/3-5m/5m+）の色分け表示
- **課題**: Shapefileの変換、座標系の確認

#### 5. 土砂災害警戒区域ポリゴン
- **再現性**: ★★★☆☆
- **データ**: 国土数値情報 Shapefile（取得済み）
- **作業**: Shapefile → GeoJSON変換
- **工数**: 1日
- **内容**: 土砂災害警戒区域の表示
- **課題**: 洪水と同じ変換処理

#### 6. 避難所到達圏（バッファ）
- **再現性**: ★★★☆☆
- **データ**: 避難所座標（取得済み）
- **作業**: Turf.jsでバッファ生成 + Leaflet表示
- **工数**: 1日
- **内容**: 避難所からの500m/1km圏の表示
- **課題**: バッファ計算の精度

### Tier 3: 追加データが必要（再現性: 低）

#### 7. 町別人口コロプレス
- **再現性**: ★★☆☆☆
- **データ**: 人口データ（取得済み）+ 町界ポリゴン（未取得）
- **作業**: 町界Shapefileの取得 + GeoJSON変換 + 人口データ結合
- **工数**: 2-3日
- **課題**: 町界データの取得、ポリゴンと人口データのマッチング

#### 8. 医療機関マーカー
- **再現性**: ★★☆☆☆
- **データ**: 医療機関CSV（取得済み、座標なし）
- **作業**: 住所→座標変換（ジオコーディング）+ マーカー表示
- **工数**: 2-3日
- **課題**: ジオコーディングの精度、API制限

#### 9. 文化財マーカー
- **再現性**: ★★☆☆☆
- **データ**: 文化財CSV（取得済み、座標なし）
- **作業**: 住所→座標変換
- **工数**: 2-3日
- **課題**: ジオコーディングの精度

### Tier 4: 高度な分析（再現性: 低）

#### 10. 到達圏分析（アイソクロン）
- **再現性**: ★☆☆☆☆
- **データ**: 道路ネットワーク（未取得）
- **作業**: OSRM/GraphHopper API + アイソクロン生成
- **工数**: 3-5日
- **課題**: 道路データの取得、ルーティングエンジンの設定

#### 11. 人口密度ヒートマップ
- **再現性**: ★☆☆☆☆
- **データ**: 人口メッシュデータ（未取得）
- **作業**: 国土数値情報人口メッシュの取得 + 表示
- **工数**: 2-3日
- **課題**: メッシュデータの取得・処理

## 推奨実装順序

### 第1段階（1-2日）: 即座に価値を提供
1. 生活空白地帯ヒートマップ
2. バス停密度ヒートマップ
3. 公園面積コロプレス

### 第2段階（2-3日）: リスク可視化
4. 洪水浸水想定区域ポリゴン
5. 土砂災害警戒区域ポリゴン
6. 避難所到達圏バッファ

### 第3段階（3-5日）: データ補完
7. 町別人口コロプレス
8. 医療機関マーカー（ジオコーディング）
9. 文化財マーカー（ジオコーディング）

### 第4段階（5-10日）: 高度な分析
10. 到達圏分析
11. 人口密度ヒートマップ

## 実装開始の提案

**第1段階**から開始することを推奨します。既存のデータと分析結果を活用でき、即座に価値の高い可視化が可能です。
