磐田市オープンデータ分析（テーマ15選）

磐田市の公開オープンデータによる地域分析。基準は2022年（人口167,663人）。全テーマを「問い → 仮説 → 検証 → 結論」の型で実施し、校正表による欠陥監査を経て v2 に作り直した成果物です。

ダッシュボード（スタンドアローン版）データを埋め込んだ単体版。全指標とグラフ、GISマップを1ページで。 テーマ7 深掘り：食料品・買い物アクセス食料品店舗417件の分布マップと、買い物アクセス困難地域マップ。 GISマップ v2地図で見る分析レイヤー。

データの出典・再現条件は各レポートとテーマ別フォルダの metadata に記録しています。分析スクリプトはファイル数が膨大なため同梱していません。
